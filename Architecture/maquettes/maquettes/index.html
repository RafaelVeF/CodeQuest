Mode d'emploi

Prévisualiser et itérer

HTML/CSS statique

1. Ouvrir un écran

Chaque carte ouvre la page complète. Les liens de navigation sont fonctionnels entre les écrans.

2. Tester les états

Boutons, onglets, filtres, thème clair/sombre, formulaires et éditeur sont simulés en JavaScript.

3. Passer à l'implémentation

Les tokens et composants du design system sont pensés pour React + Tailwind.

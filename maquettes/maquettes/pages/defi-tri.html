Énoncé

Tri fusion stable

300 + 60 pts

Écris une fonction merge_sort(values) qui renvoie une nouvelle liste triée par ordre croissant, sans modifier la liste d'entrée. Le tri doit être stable : deux éléments égaux conservent leur ordre d'origine.

Contraintes

  • 0 ≤ len(values) ≤ 100 000
  • Valeurs entières entre -10⁹ et 10⁹
  • Complexité attendue : O(n log n)
  • La liste d'entrée ne doit pas être modifiée

Exemples

exemples
›[3, 1, 2] → [1, 2, 3]
›[] → []
›[2, 2, 1] → [1, 2, 2]
